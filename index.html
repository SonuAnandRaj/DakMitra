User Guide

Master the DakMitra app with this quick beginner's guide.

🔍 Searching for Records

The main Search tab allows you to instantly find any postal record in the database.

  • Smart Typing: Type a partial address, and the app will find the closest matches even if you misspell it slightly.
  • Voice Search: Tap the red microphone icon 🎙️ in the search bar to simply speak the address or PIN code.
  • Filters: Tap the "⚙️ Search Options" button to strictly filter results by a specific Office or PIN.

⭐ Favorites & Directory

Keep your most important data accessible and organized.

  • Saving Favorites: Tap the Star icon next to any search result to save it. You can view all saved items in the Favorites tab.
  • Using the Directory: Open the Directory from the sidebar to view all addresses grouped neatly by their main Post Office. It is perfect for getting a bird's-eye view of an area.

📝 Editing Data & Approvals

DakMitra is community-driven. You can suggest corrections to any record.

  • Proposing an Edit: Tap on any search result to expand it, then tap ✎ Edit. Change the details and submit.
  • The Approval Process: Your edit won't go live immediately. It goes to the Approvals tab where other colleagues must vote "👍 Approve" before the master database is updated.
  • Adding New Records: Go to the Upload Data tab to manually type in brand new addresses that are missing from the database.

📶 Working Offline

DakMitra saves a secure copy of the database directly to your phone. If you lose internet connection while out on delivery or in a remote office, you can still search the database instantly. The app will automatically sync new data the next time you have a stable connection.
